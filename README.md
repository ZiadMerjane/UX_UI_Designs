# 💄 Morocco Cosmetics – UX/UI Design (Laptop Version)

Welcome to the UX/UI design concept for **Morocco Cosmetics**, a modern beauty brand website tailored for desktop/laptop viewports. This project focuses on clean visuals, user-friendly layout, and an elegant presentation of cosmetic products.

## 🖥️ Project Features

- ✨ **Homepage** – Eye-catching hero section, featured collections, and brand introduction  
- 🛍️ **Product Display** – Well-structured layout for showcasing items with details  
- 🧭 **Simple Navigation** – Top menu bar for easy browsing  
- 📧 **Newsletter Section** – Clean contact and subscription area

> 🎯 This version is optimized for laptop/desktop screens only (no mobile or tablet views included).

## 🛠 Tools Used

- **Figma** – Used for creating all design components and layout  
- **Canva** – For any branding elements and visual styling support
